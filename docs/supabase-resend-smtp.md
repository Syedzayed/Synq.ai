# Integrating Supabase Auth Email Delivery with Resend SMTP

This guide details the end-to-end steps to route all authentication-related emails (signup confirmations, verification updates, password resets, magic links, etc.) generated by Supabase Auth through **Resend** using SMTP credentials.

---

## 📬 SMTP Server Credentials

Use the following parameters inside the Supabase Dashboard SMTP settings page:

| Parameter | Value |
| :--- | :--- |
| **SMTP Host** | `smtp.resend.com` |
| **SMTP Port** | `465` (Secure SSL/TLS) |
| **SMTP Username** | `resend` |
| **SMTP Password** | *Your Resend API Key* (e.g., `re_123456789...`) |
| **Sender Email** | `noreply@synq.app` (or your verified domain sender) |
| **Sender Name** | `Synq` |

---

## ⚙️ Step-by-Step Configuration Guides

### 1. Resend Setup Guide
Before configuring Supabase, you must ensure Resend is ready to accept SMTP relays:
1. Log in to your [Resend Dashboard](https://resend.com).
2. Navigate to **Domains** and ensure your sending domain (e.g., `synq.app` or your custom domain) is verified with the correct SPF and DKIM DNS records.
3. Navigate to **API Keys**.
4. Click **Create API Key**.
   * Give the key a name (e.g., `Supabase SMTP Key`).
   * Select the **Sending Access** permission.
   * Save the API key safe. It will serve as your **SMTP Password**.

### 2. Supabase Configuration Guide
To apply the Resend SMTP relay settings in Supabase:
1. Log in to the [Supabase Dashboard](https://supabase.com/dashboard).
2. Open your project, and navigate to **Project Settings** (gear icon) > **Auth**.
3. Scroll down to the **SMTP Settings** section.
4. Toggle **Enable Custom SMTP** to **ON**.
5. Fill in the credentials:
   * **Sender Email**: Enter your verified Resend email address (matching your `RESEND_FROM_EMAIL` value, e.g., `noreply@synq.app`).
   * **Sender Name**: `Synq`
   * **SMTP Host**: `smtp.resend.com`
   * **SMTP Port**: `465`
   * **SMTP Username**: `resend`
   * **SMTP Password**: Paste your **Resend API Key**.
6. Click **Save** at the bottom of the page.

### 3. Verification & Redirect URLs
Ensure Supabase is configured to redirect users back to the correct paths:
1. Navigate to **Auth Settings** > **Redirect URLs** in Supabase.
2. Ensure your domain redirect lists include:
   * `http://localhost:3000/auth/callback` (Local Development)
   * `https://synq-ai-ten.vercel.app/auth/callback` (Production)
   * `http://localhost:3000/login`
   * `https://synq-ai-ten.vercel.app/login`
   * `http://localhost:3000/reset-password`
   * `https://synq-ai-ten.vercel.app/reset-password`

## 🛠️ Troubleshooting Guide

### 1. Connection Refused / Timeout Errors
* **Cause**: SMTP Port 465 requires SSL. Some environments restrict port 465.
* **Solution**: Check if Port `587` with STARTTLS works in your Supabase configuration panel as a fallback if the connection hangs.

### 2. "Sender Refused" or Emails in Spam
* **Cause**: Your Resend domain is not fully verified, or you are trying to send from `noreply@synq.app` without owning the domain credentials.
* **Solution**: Verify the domain DNS setup in Resend, or use the Resend testing sandbox sender `onboarding@resend.dev` only for temporary developer previews.

### 3. Invalid API Key Error
* **Cause**: The API key has expired, was deleted, or was copied with surrounding white spaces.
* **Solution**: Create a new API key with full sending scopes and ensure the string is copied perfectly.
